# 目标技能骨架

创建时按实际模式取用；方括号表示需要填入的目标内容，不作为未完成模板交付。已有技能保留适用结构，无须重套。

```markdown
---
name: [lowercase-skill-name]
description: [能力、使用场景、必要的误触发边界]
---

# [技能名称]

[用户要得到的结果，以及实际依赖]

## 工作流

1. [输入与前提检查，缺失条件的处理]
2. [核心行动，按需引用专业材料或脚本]
3. [完成标准，结果验证与交付]

## 判断方法

[方法/模型的触发条件、证据编号、行动和失效条件]

## 异常与恢复

[已观察到的症状 → 处理 → 无法完成时的交付边界]

## 来源与时效

[指向实际的来源记录，以及影响能力的日期/版本]
```

人物视角追加表达约定、公开立场/推断标签和知识截止日期；主题技能追加共识与分歧；专业工作流追加真实工具契约和产物验收。只有对执行有帮助的内容才进入目标入口。

长内容蒸馏用 [能力卡结构](content.md#能力卡与记录) 保存方法，用入口按任务指向实际卡片；不把整份研究复述塞进入口。单独发布方法时保留它运行所需的依据、前提、资源和边界。
